# Curso de HTML e CSS

Este curso tem como objetivo:

- Compreender os fundamentos do **HTML** e a semântica das tags  
- Aplicar estilos e técnicas de **responsividade com CSS**  
- Organizar e estruturar o código para facilitar a **manutenção**  
- Explorar as funcionalidades do **Visual Studio Code** para aumentar a produtividade  
- Utilizar **Git e GitHub** para controle de versões e colaboração em projetos  
- Publicar **sites estáticos** utilizando o **GitHub Pages**  
- Integrar layouts e interfaces por meio do **Figma**, aprimorando a experiência do usuário
